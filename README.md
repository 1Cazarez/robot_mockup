# robot_mockup

## Deploy the static page

The static page is available from [`index.html`](./index.html). GitHub Pages deploys it automatically through the workflow in [`.github/workflows/static.yml`](./.github/workflows/static.yml) whenever changes are pushed to `main`.

To enable it in GitHub:

1. Open **Settings > Pages**.
2. Set **Source** to **GitHub Actions**.
3. Push to `main`, or run **Deploy static content to Pages** manually from the Actions tab.
